# Desenvolvimento Web — Atividades Acadêmicas

Este repositório contém as soluções dos desafios e projetos desenvolvidos para a disciplina de Desenvolvimento Web. O conteúdo abrange desde a estruturação semântica de páginas com HTML5, estilização com CSS (incluindo Flexbox) e manipulação lógica com JavaScript.

## Sobre o Projeto

O objetivo deste repositório é consolidar o aprendizado prático em desenvolvimento front-end, aplicando boas práticas estruturais, visuais e lógicas exigidas nas atividades da disciplina.

---

## Etapas do Projeto

### Semana 01 — Estrutura Base e Formulário de Inscrição (HTML)
*Projeto prático desenvolvido com a temática de um Blog do Corinthians.*

Estruturação semântica da página e implementação de um formulário de inscrição.
- **Estrutura Base:** `<!DOCTYPE html>`, tag `<html>` com `lang="pt-BR"`, `<head>` e `<body>`.
- **Tags Semânticas:** Uso correto de `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>` e `<footer>`.
- **Formulário NATIVO (`<aside>`):**
  - Submissão via método `GET`.
  - Agrupamento com `<fieldset>` e `<legend>`.
  - Validações nativas de `minlength`, `type="email"`, `min` e `max` para idade.
  - Seleção de plano do Fiel Torcedor (`<select>`) e aceite de termos (`<input type="checkbox">`).
  - Associação correta entre `<label>` e campos via atributos `for` e `id`.

### Semana 02 — Estilização do Formulário de Inscrição (CSS)
*Projeto prático desenvolvido com a temática de um Blog do Corinthians.*

Estilização do formulário de inscrição aplicando conceitos de CSS e layout com Flexbox.
- **Container do Formulário:** Configurado com largura máxima, *padding* e cor de fundo personalizada.
- **Layout com Flexbox:** Organização vertical com `display: flex`, `flex-direction: column` e `gap`.
- **Estilização dos Inputs:** Aplicação de *padding*, *border*, *border-radius* e *font-size* em `<label>`, `<input>` e `<select>`.
- **Botão Personalizado:** Destaque visual com transição e efeito `button:hover`.
- **Bônus Flexbox:** Layout responsivo lado a lado para os campos de Nome e E-mail utilizando `justify-content: space-between`.
